# 第三方组件与素材

赛车、赛道、像素图集、界面和合成音频为本项目内容。中文界面使用系统字体。像素素材与音乐的生成程序随源码提供。

| 组件 | 版本 |
| --- | --- |
| jMonkeyEngine | 3.8.1-stable |
| Minie / Libbulletjme | 9.0.3 / 22.0.3 |
| LWJGL / lwjgl3-awt | 3.3.6 / 0.2.3 |
| Heart / SimMath | 9.2.0 / 1.6.0 |
| Gson / SLF4J API / Error Prone annotations | 2.11.0 / 1.7.32 / 2.27.0 |

组件的原始许可文本和上游来源记录见 [licenses](licenses/)。Windows 便携包保留依赖 JAR 及其许可，自带 Eclipse Temurin Java 运行时。运行时的版本和源代码修订见包内 `runtime/runtime-info.json`，各模块许可见 `runtime/legal/`。[Eclipse Temurin](https://adoptium.net/temurin/) · [OpenJDK 源码](https://github.com/adoptium/jdk25u)
