# 方程式试车工坊游玩指南

## 第一圈

在主菜单打开「新手入门 · 四图驾驶指南」，选择海湾、林地、公园或港区。第一次驾驶可以先练起步和停车，再自由熟悉路线。从「开始游戏」也可直接进入比赛。按顺序通过检查点才能取得有效圈；越界会影响本圈的个人纪录，正赛中复位还会增加罚时。

| 默认按键 | 操作 |
| --- | --- |
| W / ↑，S / ↓ | 加速、制动；停稳后继续按制动键可倒车 |
| A / D，← / → | 左转、右转 |
| 空格，R | 全制动、复位或重试 |
| Tab / C，G | 切换镜头、切换幽灵显示 |
| H / F1，Esc，Enter | 显示帮助、暂停或返回、确认 |
| F12，F6 | 截图、重新载入像素素材 |

在「设置 → 手柄与操作设置」选择并校准手柄，或进入「键盘键位设置」修改主要键和备用键。联机时房主持续计时，客机暂停会向房主发送全制动。

## 车库、计时与回看

在车库调整动力、制动、悬挂和气动参数，可以把常用配置命名保存。想比较两种调校时，固定车辆和路线、每次只改一个参数，再用试驾报告比较。计时挑战可显示最佳圈幽灵。打开已保存的比赛回看，拖动时间轴，或用左右方向键逐帧查看；按 M 可按车辆和事件类型查找标记。

## 创作与多人

赛道编辑器可调整路线、道宽和布景，草稿可保存、试跑和导出。导入他人分享的赛事包后，先在本机完成地图验证，再启用相应赛事。联机时由一人建房，其他玩家输入房主显示的地址和端口加入，核对车辆和赛道后准备。主菜单中的迷你四驱车可单独组装车辆、编辑轨道和比赛。

## 保存与备份

正常退出游戏后，复制解压目录中的整个 `userdata` 文件夹即可备份。升级时把旧存档的副本放入新解压目录的同名位置。画面、音量和车库配置存于 `profile.json`，键位与手柄设置分别在 `keyboard.json` 和 `controls.json`；赛道、回看、赛事和幽灵还有各自的数据文件。
